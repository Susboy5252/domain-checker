## 🛡️ DeFi Domain Checker

A high-performance, Go-based security engine designed to protect Web3 frontends from DNS hijacking, unauthorized certificate issuance, and infrastructure compromise. 

**Core Capabilities:**
* ⚡ **Real-Time Monitoring:** Runs sub-minute checks on DNS records, WHOIS status, and SSL certificates, routing critical alerts directly to Telegram or Discord.
* 🔍 **Infrastructure Auditing:** Powers comprehensive reviews of registrar settings, security headers, third-party JS scripts, and wallet-connection signatures.
* ⛓️ **On-Chain Fingerprinting:** Maintains a free, open-source registry of verified frontend fingerprints on the Base network, ensuring transparent and immutable security for the ecosystem.
